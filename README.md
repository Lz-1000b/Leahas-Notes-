# Bristol Street Crime / Map Analysis

## Project Overview

The Bristol Street Crime Map Analysis project aims to develop an interactive website that visualises and analyses reported street crime incidents across Bristol using publicly available data from Bristol Open Data.

The website will allow users to explore crime incidents through an interactive map, compare crime levels between different areas and identify patterns in reported criminal activity across the city.

The application will present crime information in a clear and accessible format, helping users understand where different types of crime occur, which locations experience higher crime levels and whether certain areas experience consistent patterns of criminal activity.

## Project Objectives

The main objectives of this project are:

1. **Interactive Crime Map:** Display reported street crime incidents across Bristol using an interactive map.
2. **Crime Categories:** Allow users to explore different types of crime, such as burglary, vehicle crime, shoplifting and anti-social behaviour.
3. **Area Comparison:** Enable users to compare reported crime levels between different Bristol locations.
4. **Crime Information:** Display information about individual crime incidents, including crime category, location and available reporting details.
5. **Crime Patterns:** Identify popular crime hotspots and areas experiencing consistent levels of reported crime.
6. **Data Visualisation:** Present crime statistics using maps, charts and other visual representations.

## Data Source

The project will use publicly available street crime information from Bristol Open Data. The dataset contains information about reported crime incidents, including crime categories and geographical locations.

The data will be used to create interactive visualisations and help users explore crime patterns across Bristol.

## Intended Users

The website is intended for:
- Bristol residents interested in understanding crime in their local area.
- People comparing crime levels across different parts of Bristol.
- Researchers and students interested in crime patterns and data analysis.
- Anyone interested in exploring publicly available crime information.
