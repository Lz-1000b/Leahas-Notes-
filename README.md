
# Bristol Street Crime / Map Analysis

## Project Overview

My project is to create a website called Bristol Street Crime / Map Analysis, using publicly available crime data from Bristol Open Data to create an interactive map showing reported street crime across Bristol.

The website will allow users to view different types of crime, explore where incidents have been reported and compare crime levels between different areas. Users will also be able to identify crime hotspots and areas where crime appears to happen more consistently.

## Project Objectives (features)

**Interactive Map:** Show reported crime locations across Bristol on a visual map.
**Crime Types:** Allow users to view different types of crime, such as burglary, vehicle crime, shoplifting and anti-social behaviour.
**Area Comparison:** Let users compare crime levels between different areas of Bristol.
**Crime Information:** Show available information about reported incidents, including crime type, location and date.
**Crime Hotspots:** Highlight areas with higher numbers of reported crimes and identify patterns.
**Data Visualisation:** Use maps and charts to make crime information easier to understand.

## Dataset Description

I will use this data from bristols open data set to forward information creating an interactive map and analyse crime patterns across different areas. The data will also help users compare locations, see which crime types are more common and identify areas with higher levels of reported crime.

## Intended Users

The website is aimed at Bristol residents, people interested in comparing different areas, students and anyone who wants to explore crime information across Bristol.

## Expected Outcome

I am aiming to have created a working website where users can interact with a map of Bristol, explore different crime types, compare areas and view crime statistics in a simple and understandable way.
